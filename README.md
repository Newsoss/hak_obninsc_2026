# MicroCleaner

Выравнивает освещение на микроснимках: убирает виньетирование, неравномерную подсветку, пятна от пыли на оптике и жёлтый оттенок лампы.

Если вы снимаете под микроскопом, то знаете: углы кадра темнее центра, на каждом снимке одни и те же серые пятна от пылинок, а фон отдаёт жёлтым. Править это вручную в фоторедакторе долго, и каждый раз получается по-разному. MicroCleaner делает это по калибровочному кадру — одинаково для всей серии и за секунды.

## Как это работает

Метод — flat-field correction. Кроме снимка препарата нужен кадр **светлого поля**: тот же микроскоп, объектив и свет, но вместо препарата пустой участок стекла. На нём видно только то, как оптика искажает освещение. Делим снимок на этот кадр — искажения уходят:

```
C = (R − D) / (F − D) × m
```

R — снимок, F — светлое поле, D — темновой кадр (снят с выключенным светом, необязателен), m — средняя яркость светлого поля, чтобы общая яркость не менялась.

Деления на ноль нет: знаменатель ограничен снизу. Расчёт идёт во float32, 16-битный TIFF остаётся 16-битным. Исходники не трогаются — результат пишется в отдельный файл с суффиксом `_ffc`, рядом кладётся JSON с параметрами обработки.

Нет светлого поля? Его можно оценить: по серии из 5+ снимков (медиана) или по одному снимку (размытие). Второй способ приблизительный, и программа об этом предупреждает.

## Возможности

- сравнение «до/после» шторкой или двумя кадрами рядом, зум до пикселя, карта освещённости;
- значение пикселя под курсором в исходных единицах;
- пакетная обработка: файлы или папка целиком, одна калибровка на всю серию, на выходе ZIP со сводной картинкой;
- темновой кадр и усреднение нескольких калибровочных кадров;
- яркость, контраст, гамма, баланс белого, пресеты, сохранение настроек в файл;
- проверка калибровки при загрузке: пересвет, препарат в кадре светлого поля и т. п.;
- TIFF 8/16/32 бит, PNG, JPEG, BMP; метаданные TIFF (размер пикселя, камера, дата) переносятся в результат;
- проверка точности метода на эталонном снимке — вкладка «О методе».

## На сервере

По умолчанию сайт открыт всем. Чтобы поставить пароль или поменять лимиты, создайте рядом с `docker-compose.yml` файл `.env` по образцу `.env.example`. Пароль задаётся в `ACCESS_PASSWORD`; лимиты на размер файлов, частоту запросов и память уже выставлены под обычный VPS.

## Ограничения

Это инструмент для исследовательской обработки, а не для диагностики. Нейросетей нет — только арифметика над пикселями, так что новых деталей на снимке появиться не может. Если снимки идут в публикацию, храните исходники и прикладывайте JSON с параметрами обработки.
