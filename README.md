# MicroCleaner

Убирает неравномерную подсветку с микроснимков: виньетирование, пятна от пыли, оттенок лампы.

Загружаешь снимок и кадр пустого стекла (светлое поле), программа выравнивает освещение методом flat-field correction. Можно сравнить «до» и «после» и обработать сразу целую серию снимков с одними настройками. Оригиналы не меняются.
