# Тестовые снимки

Синтетические кадры 1280×960, как будто снятые на одном микроскопе: тёмные углы, свет перекошен вправо, пятна от пыли на оптике, жёлтый оттенок лампы и шум матрицы.

- `bright.png` — светлое поле (пустое стекло)
- `dark.png` — темновой кадр (свет выключен)
- `sample_01.png` … `sample_06.png` — снимки препарата

Как попробовать:

1. Вкладка «Обработка»: в «Снимок» — любой `sample_*.png`, в «Светлое поле» — `bright.png`, в «Темновой кадр» — `dark.png`.
2. Вкладка «Пакет»: «Добавить файлы» → все `sample_*.png`, калибровка та же. Если светлое поле не загружать, его можно оценить по серии — снимков как раз хватает.

Пересоздать: `cd backend && python -m tools.make_samples`.
