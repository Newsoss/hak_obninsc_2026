# Свой пример для кнопки «Открыть пример»

Если папка пустая (здесь только этот файл), используется встроенный синтетический пример.
Положите сюда файлы — и кнопка «Открыть пример» и «Добавить примеры» в пакете возьмут их.
Перезапуск сервера не нужен.

## Вариант 1. Настоящие снимки с калибровкой

Лучший вариант для защиты: снимки и калибровка сделаны на одном микроскопе.

```
demo_data/
  bright.tif      ← светлое поле: тот же объектив и свет, пустой участок стекла
  dark.tif        ← необязательно: темновой кадр, свет выключен или закрыт объектив
  slide_01.tif    ← любые другие файлы — снимки препарата
  slide_02.tif
  slide_03.tif
```

Имена `bright` и `dark` обязательны (расширение любое: tif, png, jpg, bmp).
Все остальные изображения считаются снимками. Файлы отдаются как есть, без изменений.

## Вариант 2. Чистые снимки из открытого датасета + искусственная засветка

Подходит, если калибровочных кадров нет. Так предлагает и кейс (п. 5):
«открытые/учебные микроснимки и синтетический градиент освещения».

```
demo_data/
  specimens/
    tissue_01.jpg
    tissue_02.png
    tissue_03.tif
```

На каждый снимок накладываются одинаковые виньетирование, перекос света, пыль и тёплый
оттенок лампы, а светлое поле и темновой кадр генерируются к ним точно. Поэтому коррекция
должна вернуть снимок к исходному виду — это наглядная проверка корректности метода.

Требования к снимкам:
- **равномерно освещены** — иначе их собственная неравномерность останется и после коррекции;
- светлый фон (светлое поле, гистология, мазки); флуоресценция на тёмном фоне здесь не подойдёт;
- кадр обрезается по центру до 4:3 и приводится к 1280×960.

## Лицензии

Используйте только открытые снимки с подходящей лицензией (CC0, CC BY и т. п.) и указывайте
источник на защите. Реальные лабораторные изображения — только с разрешения правообладателя
и после обезличивания.
